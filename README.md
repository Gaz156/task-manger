Count Characters – Command Line Python Script

A simple Python command-line tool that takes a word (or sentence) as an argument and prints the number of characters.
This project is ideal for learning how argv, command-line arguments, and basic string handling work in Python.

⸻

🚀 How It Works

The script reads input from the command line using sys.argv.
It then prints:
	•	The input word/text
	•	The number of characters in it

If the user doesn’t provide any argument, it prints a helpful usage message.
